# Maintainers

This file lists the Maintainers of the FINOS Architecture as Code project, also known as CALM. It is the project-wide roster and covers every repository in the project.

The roles of **Maintainer** and **Lead Maintainer**, the qualifications for becoming a Maintainer, and the processes for electing and removing Maintainers are defined in [GOVERNANCE.md](GOVERNANCE.md).

**Lead Maintainer:** @rocketstack-matt

The Lead Maintainer is the project's interface with the FINOS team and Board. The role is subject to election by the Maintainers as set out in [GOVERNANCE.md](GOVERNANCE.md); the entry above records the current position.

## Updating this file

All changes to the maintainer list are managed openly:

- **Submit a Pull Request** to this file for any addition, removal, or update.
- **Where the change requires a Maintainer vote** — the election or removal of a Maintainer or the Lead Maintainer — document or link to the vote outcome in the PR description or comments. See [GOVERNANCE.md](GOVERNANCE.md) for the voting process and the notice periods that apply to removal.
- This process creates a public audit trail of project leadership over time.

Please email **help@finos.org** whenever this file is updated with a change to maintainership.
